# Return Policy

## General Return Window
Customers may return most items within 7 days of delivery for a full refund,
provided the item is unused and in its original packaging.

## Electronics Returns
Electronics (headphones, speakers, keyboards, mice) can be returned within
7 days only if unopened. Opened electronics are not eligible for return
unless defective — see the Warranty Policy for defective item handling.

## Return Shipping Fees
Return shipping is free for defective or incorrect items. For other returns,
a return shipping fee of ₹99 applies, deducted from the refund amount.

## How to Initiate a Return
To initiate a return, contact support with your order ID within the return window.
